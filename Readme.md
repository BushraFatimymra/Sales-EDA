# Sales Data Exploratory Data Analysis

## Overview
This project explores sales data using Python to identify patterns in customer behavior, regional performance, product categories, payment methods, and profitability.

## Objectives
- Explore and assess data quality.
- Analyze customer segments and regional sales patterns.
- Visualize sales and profit distributions.
- Investigate discounts, returns, and payment methods.
- Identify key findings from the dataset.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `sales.ipynb` — Contains the complete exploratory data analysis.
- `sales_data.csv` — Dataset used for the analysis.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open `sales.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.

Ensure `sales_data.csv` is in the same directory as the notebook.
